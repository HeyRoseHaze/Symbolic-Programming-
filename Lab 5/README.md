# Lab 5

## Task 1
Write two functions that return the $n$-th term of the Fibonacci sequence:
1. **Iterative approach**
2. **Recursive approach**

After implementing the functions, use the `timeit` module to compare the execution time of both methods depending on the value of $n$ (from 0 up to approximately 30–40). Finally, present the benchmarking results on a graph.

## Task 2

Write a function that takes a sequence as an argument (such as a **list**, **tuple**, or any other **iterable**) and returns:
* The **index** and **value** of the minimum element.
* The **index** and **value** of the maximum element.

After defining the function, use **list comprehension** to create a list of over a dozen random integers. Finally, test your function using this generated list to verify the results.
